# Database Transactions & Flashback Demo

Набор SQL-скриптов для демонстрации транзакций, уровней изоляции и технологий восстановления данных (Flashback) в СУБД (Oracle).

## 📋 Содержание

### 1. Подготовка данных (`scripts/setup/`)
- `02_create_tables.sql` — создание таблиц и заполнение тестовыми данными.

### 2. Управление транзакциями (`scripts/transactions/`)
- **Автономные транзакции** — независимые операции (`PRAGMA AUTONOMOUS_TRANSACTION`).
- **Read-Only транзакции** — режим «только чтение» с фиксированным состоянием данных.
- **Savepoints** — точки сохранения для частичного отката.

### 3. Уровни изоляции (`scripts/isolation-levels/`)
- **Аномалии консистентности** — проблемы при параллельных сессиях.
- **Read Committed** — поведение при стандартном уровне изоляции.

### 4. Flashback (`scripts/flashback/`)
- **История данных** — просмотр состояний (`AS OF TIMESTAMP`).
- **Восстановление** — откат к нужному времени.
- **Undo Check** — проверка доступности данных в undo-сегментах.

## 🚀 Использование
1. Запустите `setup` для подготовки данных.
2. Тестируйте изоляцию в двух сессиях.
3. Изучайте Flashback через соответствующие скрипты.
